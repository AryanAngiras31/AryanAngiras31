# Aryan S Angiras
AI Engineer

I build scalable software systems and backend infrastructure powered by AI and Machine Learning.

### Selected Work

* **Verity**
  A hallucination-resistant Natural Language Inference (NLI) engine. Built with a concurrent Rust backend (Actix-Web), Qdrant, and ONNX models to verify scientific claims without relying on generative LLMs.

* **HRMS AI Microservices**
  Production-deployed, containerized FastAPI microservices. Includes a Candidate Ranking Engine and high-accuracy parsing pipelines utilizing Llama 3.3, PaddleOCR, and dense vector embeddings.

* **GlassHeart CDSS**
  A clinical decision support system utilizing tuned Random Forest and XGBoost models to evaluate heart failure mortality along with providing explainability through SHAP and statistical tests.
