### Selected Projects

* **[Sunder](https://github.com/AryanAngiras31/Sunder)** — *Agentic Zero-Trust Codebase Testing Framework*  
  An AI testing framework for enterprise codebases built using LangGraph. Features an Evaluator-Optimizer state machine that bypasses authentication barriers to run deep logic testing. Utilizes a custom Tree-sitter and SQLite relational engine to parse code, and safely executes generated tests across 20+ languages inside a read-only Docker sandbox.

* **[Verity](https://github.com/AryanAngiras31/Verity)** — *High-Concurrency Scientific Claim Verification Engine*  
  A Natural Language Inference (NLI) engine that verifies scientific assertions against a 36,000+ document corpus without relying on generative LLM hallucinations. Achieves a 10x inference speedup on commodity CPUs using INT8 dynamic quantization and batched tensor processing, backed by a concurrent, lock-free Rust (Actix-Web/Tokio) backend and Qdrant vector search.

* **HRMS AI Microservices** — *Production Enterprise AI Services*  
  Three independent AI microservices containerized using FastAPI and Docker Compose for an enterprise HRMS. Features a sub-200ms candidate-ranking engine built with Qdrant vector database and task-specific Bi-Encoders, alongside resume and tax invoice parsing pipelines combining Llama 3.3 and OCRs.

* **[KrivaCare](https://github.com/AryanAngiras31/KrivaCare)** — *Multimodal Healthcare AI with Uncertainty-Guided Fusion*  
  A medical diagnostic pipeline built with PyTorch that combines patient clinical text and imaging data. It uses an uncertainty-driven "late fusion" approach to evaluate the text and image models independently and then determines the final classification. Built-in explainability features help clinicians understand and trust the model's reasoning.
